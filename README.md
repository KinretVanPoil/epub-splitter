# EPUB Splitter — Native Android (Kotlin & Jetpack Compose)

**EPUB Splitter** — це нативний Android-застосунок для читання та розбиття електронних книг формату `.epub` на фрагменти по **~15 000 символів** із можливістю швидкого копіювання в буфер обміну для подальшої обробки (в ШІ, конспектування тощо).

---

## 🚀 Ключові можливості

1. **Direct ZIP & XML Parsing (Безпечний парсинг):**
   * Пряме читання архіву EPUB засобами `java.util.zip.ZipFile`.
   * Жодних проблем з CORS, WebIntoApp або нестабільними веб-рендерами.
   * Підтримка відкриття `.epub` безпосередньо з провідників, Telegram або Google Drive.

2. **Алгоритм Smart Split (~15 000 символів):**
   * Розбиття за абзацами (`\n\n`), реченнями (`. `, `! `, `? `) та межами слів.
   * Текст ніколи не обрізається посеред слова чи речення.

3. **Копіювання в 1 клік:**
   * Плаваюча кнопка **«Копіювати 15k» (📋)** миттєво зберігає весь поточний фрагмент у буфер обміну Android.

4. **100% надійність збереження (Ніякої «амнезії»):**
   * Книга та остання відкрита сторінка надійно зберігаються у внутрішньому сховищі додатка.
   * При наступному відкритті додаток моментально повертає вас до останнього місця читання.

5. **Комфорт читання:**
   * 3 теми оформлення: **Світла**, **Сепія** (тепла для очей) та **Темна** (AMOLED/нічна).
   * Регулювання розміру шрифту (12sp – 32sp).
   * Функція **«Не вимикати екран»** (Wake Lock).
   * Можливість ручного переходу на будь-яку сторінку.

## 🛠️ Як зібрати APK через GitHub Actions

Проект повністю налаштований для автоматичної збірки в хмарі GitHub. Вам не потрібно встановлювати Android Studio чи SDK на комп'ютер.

### Крок 1. Створіть новий репозиторій на GitHub
1. Перейдіть на [GitHub](https://github.com) і створіть новий репозиторій (наприклад, `epub-splitter`).

### Крок 2. Завантажте файли проекту в репозиторій
Виконайте у терміналі в папці проекту:
```bash
cd C:\Users\Ivan\.gemini\antigravity\scratch\epub-splitter-android
git init
git add .
git commit -m "Initial commit: Native Android EPUB Splitter"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГІН/epub-splitter.git
git push -u origin main
```
*(Або просто перетягніть файли в репозиторій через вебінтерфейс GitHub)*.

### Крок 3. Автоматична збірка APK
1. Як тільки код з'явиться в гілці `main`, у вкладці **Actions** вашого репозиторію автоматично запуститься workflow **«Build Android APK»**.
2. Збірка триває приблизно 1.5–2 хвилини.
3. Після завершення відкрийте запуск збірки (зелена галочка ✅).
4. У розділі **Artifacts** завантажте:
   * **`epub-splitter-debug`** або **`epub-splitter-release`** (всередині буде готовий `.apk` файл).

### Крок 4. Встановлення на смартфон
1. Надішліть завантажений `.apk` файл на свій Android-смартфон (через Telegram, Google Drive або кабель).
2. Натисніть на файл і дозвольте встановлення з невідомих джерел.
3. Готово! Додаток працює надійно, швидко й повністю автономно.
